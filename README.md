# PebbleSnapCounter

An app to count things and calculate percentages using the Pebble buttons or finger motion (snapping/tapping)

The goal of this app is to introduce a whole new way of interacting with the watch using IMU detected gestures (snapping and tapping in different directions).

Right now this app allows you to easily count things or the percentage of something by simply tapping the finger against a table or the thigh
